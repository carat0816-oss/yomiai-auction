# 🃏 読み合いオークション

AIと札を出し合う心理戦カードゲームです。遊ぶとデータがたまり、そのデータで分析と予測モデルづくりまでできる Streamlit アプリです。

- **データ収集**：対戦ごとに、出した札・考えた時間・AIの読みを Googleスプレッドシートに保存します
- **データ分析**（📊 みんなのデータ）：「得点が大きいほど大きい札を出す？」「負けた直後は強気になる？」などの問いごとに、データから計算した答え・グラフ・読み方を並べています。プレイヤーのカルテ、AIの読みの的中率の推移、CSVの書き出しもあります
- **予測モデル**：「相手が次に出す札」と「この局面から勝てるか」を学習したAIが対戦相手になります。新しい版は `train_model.py` で作ります（下の「AIの版」）

## 遊ぶ

**https://yomiai-auction.streamlit.app/**

- 開いて止まっているときは、アプリが眠っています。表示されるボタン（Yes, get this app back up!）を押して1分ほど待つと起きます
- 対戦のあと「みんなのデータに送る」で同意して送ると、誰がどこで遊んでも同じGoogleスプレッドシートにたまります

## ルール

- お互いに 1〜10 の手札を持ち、得点カード 1〜10 をシャッフルして10ラウンド戦います
- 得点カードが公開されたら、両者が伏せて1枚ずつ出します。大きい数を出した方が、その点をもらいます
- 同じ数なら「相打ち」です。その得点カードは誰のものにもならず流れます（両者の札も消えます）
- 勝ち確定のラインは「流れていない点の過半数」です。最初は28点で、点が流れるたびに下がります
- 使った札は戻りません。出した札は公開されるので、相手の残りの手札はわかります

同時に出すゲームなので、決まった正解の札はありません。読み合いのゲームです。

相打ちのほとんどは偶然ですが、狙う意味がある場面もあります。両者の最強札が同じで大きい得点カードが出たとき（ぶつけて止めるか、最弱札で譲って最強札を温存するか）と、リードしているとき（点が流れると相手が追いつきにくくなる）です。AIは相打ちを特別扱いせず、相打ちになった後の勝率も含めて計算して札を選びます。

## 対戦画面（盤面）

対戦の盤面は、Streamlit Components v2 で作った専用の部品です（`board/` の HTML・CSS・JS）。Python が局面を `data` で渡し、札が選ばれると JS が `setTriggerValue("play", …)` で返します。

- **点数**：綱引き型のバーで表示します。あなた（青）、まだ誰も取っていない点（灰）、AI（オレンジ）の順に並び、真ん中の白線が勝ち確定のラインです。バー全体は「流れていない点」なので、点が流れるとラインの点数も下がります（例：5点流れたら26点）
- **得点カード**：点数のバーと同じ並びで、3つの枠に分けて表示します（左＝あなたが取った、真ん中＝まだ出ていない、右＝AIが取った）。取ったカードには何ラウンド目かを書き、いまの得点カードは金色に光ります。相打ちで流れたカードは真ん中の枠の下に灰色で出ます。取れば勝ち確定になる得点カードには「あなたが取れば勝ち確定！」と出ます
- **AIの残りの手札**：1〜10を常に並べます。使った札は暗くして、使ったラウンドを書きます。最強札、合計、8以上の枚数も出します
- **場**：AIの札は最初から伏せて置いてあります。札を出すと場に飛び、両方がめくれて、勝った側の点数へ点が飛んでいきます
- **ふりかえり**：場の上の帯に、前のラウンドの結果とAIの読みが当たったかを出します。横の欄（画面が狭いときは下）では、AIがあなたの手札1枚ずつにつけていた確率と、AIが札ごとに出した期待勝率を見られます。対戦中は画面を横に広く使い、盤面の右にこの欄と「これまでの対戦」を並べます
- 対戦中の勝率予想のメーターは、まだ精度が低いので出していません（勝ち確定ラインだけを表示）
- **操作**：クリックのほか、キーボードの 1〜9・0（＝10）でも出せます
- **考えた時間**：ブラウザ側で、札が出せるようになってからクリックまでを測ります
- まだ公開されていない得点カードの順番は、ブラウザに送りません

## AIのしくみ

1. **相手の手の予測**：人間が札を選んだ1回ごとに、手札の候補1枚＝1行の表を作ります。「その札を出したか（1/0）」を2値分類で学習し、候補の中で確率を合計1にそろえます
   - 特徴量の例：得点カードの値と順位、点差、勝ち確定まであと何点か、流れた点、残りの点に占める割合、候補の札の手札内順位、相手の最強札、前のラウンドの結果、その人のここまでの強気さ
2. **勝率モデル**：ラウンドの合間の局面から、最終的に勝つかどうかを予測します（LightGBM）
3. **札の選び方**：自分の札ごとに「相手の札の予測確率 × そのあとの勝率」を足し合わせて期待勝率を出します。期待勝率が最善に近い札だけを候補にして、その中からくじで選びます（良い札ほど選ばれやすい）。迷いはしても、明らかに悪い札は出しません
   - AIの強さ（やさしい・ふつう・本気）で、候補にする幅（最善から何ポイント以内か）を変えます
   - AIは人間が札を出す前に自分の札を決めます。後出しはしません

人間の手が150手（15試合）に届かないうちに作った版では、相手の読みに簡単なルール（得点に見合った順位の札を出す）を使います。勝率モデルは、ボット同士の対戦20000試合で下地を作り、そのモデルで動くAIを4000試合戦わせた記録と人間の対戦も加えて学び直します（次の版から。Yomi 1.0 はボット同士1500試合で学習）。残っている札を1枚ずつ表す特徴量も使います。

## AIの版（モデルの更新）

対戦AIは「Yomi 1.0」「Yomi 1.1」のような**決まった版**です。公開アプリは学習済みの版を読み込むだけで、勝手に学習し直すことはありません。新しい版は、管理者が好きなタイミングで手元で作ります。

```sh
.venv\Scripts\python train_model.py --name "Yomi 1.1" --notes "50試合に増えたので学習し直し"
git add models
git commit -m "AIの版 Yomi 1.1 を追加"
git push
```

- スプレッドシートの最新の対戦で学習します。人ごとに分けた交差検証で「読みの的中率」を測り、ボット相手の勝率もあわせて記録します
- `models/<版>.joblib` に学習済みモデルを、`models/registry.json` に版の一覧（公開日・学習データ量・成績・メモ）を保存します
- push すると、Streamlit Cloud が自動で新しい版を読み込みます。新しい版が「現役」（最初に選ばれている対戦相手）になります
- 古い版も残ります。対戦前の画面で選べるので、版どうしの強さを比べられます。リリースノートも同じ画面に出ます
- オプション：`--model`（ロジスティック回帰・決定木・ランダムフォレスト・LightGBM）、`--features`（カンマ区切り）、`--no-activate`（現役にせず一覧に追加だけ）、`--local`（data/ の記録を使う）
- 学習済みモデルを手元とクラウドで同じように読めるよう、`requirements.txt` で scikit-learn・LightGBM・numpy・joblib の版を固定しています。これらを上げるときは、版を作り直してください

## 手元で起動

Windows では `start.bat` をダブルクリックします。初回は専用の仮想環境を作り、ライブラリを入れます。

手動で起動する場合：

```sh
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

## みんなのデータ（Googleスプレッドシート）

`.streamlit/secrets.toml` にサービスアカウントとスプレッドシートの URL を書くと、そのスプレッドシートに2つのタブを自動で作って保存します。いまは sorting-factory と同じスプレッドシート・同じ鍵を使っています。

| タブ | 1行の単位 | 主な列 |
|---|---|---|
| `yomiai_games` | 1試合 | game_id, received_at, player, boardgame, style, ai_level, my_score, ai_score, result, read_top1（AIの読みの的中率）, read_prob, ai_model |
| `yomiai_rounds` | 1ラウンド | game_id, player, round, prize, carry, human_card, ai_card, winner, human_total, ai_total, think_ms, ai_read（AIの予測の上位3つ）, read_prob, ai_win |

- 保存されるのは、リザルト画面でプレイヤー名（必須）を入れて「データ提供に同意」した試合だけです
- 不適切な名前や、消してほしいと言われた記録は、`yomiai_games` の行を消すと1分ほどでアプリからも消えます（対応する `yomiai_rounds` の行は残っていても無視されます）
- 試合の記録は保存の前にルールどおりか検査します（使った札をもう一度出している記録などは受け付けません）
- Secrets がない場合は、手元の `data/` に同じ形で保存します（動作確認用）

Streamlit Community Cloud に置く場合は、`secrets.toml` の中身を「Settings → Secrets」に貼ります。`secrets.toml` は Git に上げないでください（`.gitignore` 済み）。

## 検証

```sh
.venv\Scripts\python test_game.py
.venv\Scripts\python test_app.py
```

- `test_game.py`：ルール（得点・相打ち・勝ち確定ライン）、特徴量、学習用の表、交差検証、AIが反則しないこと、保存形式の検査と読み戻し
- `test_app.py`：1試合を最後まで進める、同意して送る、二重送信の防止、名前が空欄だと送れないこと、みんなのデータ画面（本物・ダミー・絞り込み・プレイヤーのカルテ）

テストは一時フォルダに保存するので、本物のスプレッドシートには書き込みません。
